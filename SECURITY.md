# Signaler une vulnérabilité

Merci de contribuer à la sécurité du projet. **Ne publie pas les détails d'une vulnérabilité dans une issue publique.**

Le dépôt ne dispose pas encore d'un canal privé de signalement public configuré. Avant de diffuser le projet, les responsables doivent ajouter une adresse de contact ou activer les rapports privés de vulnérabilité sur l'hébergeur du dépôt, puis remplacer cette note par les instructions effectives.

En attendant, ne transmets pas de secrets réels ni de données privées. Les problèmes non sensibles peuvent être signalés dans une issue en limitant les détails permettant l'exploitation.

Pour un rapport utile, indique la version concernée, le contexte, les étapes de reproduction non destructives et l'impact observé. Ne teste pas les systèmes ou dépôts d'autrui sans autorisation.
